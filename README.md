# Контроль качества денситометрии (DXA) — рабочая папка

Задача хакатона: сервис, который по денситометрическому исследованию в DICOM определяет,
качественное оно или с нарушением, и какого типа нарушение.

**Главное читать здесь: [docs/findings.md](docs/findings.md)** — все находки по данным с цифрами.

## Что где

| Каталог | Что это |
|---|---|
| `dxa_real/` | Работа с реальным набором организатора: загрузка, измерения по критериям ТЗ, синтетика, честная оценка |
| `dxa_qc/` | Решение сокомандника с наложенными правками (см. `patches/`) |
| `patches/` | Патч к `dxa_qc` и инструкция, что перезапустить |
| `scripts/` | `make_synthetic_for_dxa_qc.py` — вливает синтетику в пайплайн команды |
| `docs/` | `findings.md` — находки, `validation.md` — поверка измерителя, `rotation.md` — ротация бедра, `synthetic.md` — синтетика, `team_review.md` — разбор решения команды, `cheatsheet.md` — шпаргалка по DICOM |
| `dxa_sandbox/` | DICOM-песочница: чтение, разметка, оформление результата по требованиям ЦДТ, мини-PACS |
| `out/` | Результаты прогонов, `metrics_real.json` |

## Готовые решения (папки наработок)

- `наработки от опуса/` — решение Opus (v3-конфигурация, fused-стекер).
- `наработки от фейбла/` — решение Fable (костное окно + denoise + CLAHE, синтетика артефактов v2).
- `наработки от астры/` — **гибридное решение Astra**: самодостаточный пакет `src/`
  (объединяет идеи выше + атлас-регистрацию кости), Docker и отчёт.
  Подробности — `наработки от астры/README.md`.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Распаковать `НД_для_обучения` в короткий путь (длинные имена папок ломают распаковку в Windows),
например `C:\dxa`, и запустить оценку:

```bash
.venv\Scripts\python.exe -c "import sys; sys.path.insert(0,'.'); from dxa_real.data import load_dataset, summary; print(summary(load_dataset(r'C:\dxa')))"
```

## Что уже сделано

1. **Разобран формат данных.** Размер пикселя достаётся из тега `(0040,0303) Exposed Area`
   (есть во всех 499 файлах), а не угадывается константой.
2. **Измерения по критериям ТЗ**: угол оси по средней линии позвоночника, видимость гребней
   подвздошных костей, отступы поля сканирования, выступ малого вертела, посторонние объекты.
3. **Честная схема оценки**: группировка по пациенту, вложенный подбор порога, доверительные
   интервалы по исследованиям.
4. **Синтетические нарушения** из реальных чистых снимков с защитой от артефактов генерации.
5. **Патч к решению команды** и скрипт для вливания синтетики в их пайплайн.
