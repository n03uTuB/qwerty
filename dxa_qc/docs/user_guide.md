# Руководство пользователя DXA-QC

## 1. Что делает сервис

Для каждого денситометрического исследования сервис определяет:

- анатомическую область изображения;
- класс качества (`0` — качественное, `1` — есть нарушение);
- тип(ы) выявленных нарушений.

Результат — таблица `csv`/`xlsx`, одна строка на изображение.

## 2. Подготовка данных

1. Поместите исследования в один каталог. Поддерживаются оба варианта:
   - корень набора с подкаталогом `исследования/`;
   - непосредственно каталог с подкаталогами-исследованиями (UID).
2. Внутри исследования допускается любая вложенность; сервис сам найдёт
   DICOM-файлы (в том числе без расширения).

## 3. Пакетная обработка

```bash
python -m src.predict --input /path/to/данные --output outputs/results.csv
```

По завершении будут созданы:

- `outputs/results.csv` — таблица результатов;
- `outputs/results.xlsx` — та же таблица в Excel.

Колонки: `path_to_study`, `study_uid`, `image_uid`, `anatomical_region`,
`quality_class`, `violation_type`, `processing_status`, `time_of_processing`
(а также `quality_prob`, `violation_probs`).

### Чтение результата

| Значение `processing_status` | Что делать |
|---|---|
| `Success` | результат достоверен |
| `Failure` | файл пропущен, см. колонку `error`; изображение следует проверить вручную |

## 4. Работа через API

1. Запустите сервис: `uvicorn src.api:app --host 0.0.0.0 --port 8000`
2. Откройте интерактивную документацию: `http://localhost:8000/docs`
3. Загрузите файл:

```bash
curl -F "file=@CR000001.dcm" http://localhost:8000/predict/image
```

Пример ответа:

```json
{
  "anatomical_region": "Поясничный отдел позвоночника",
  "quality_class": 1,
  "quality_prob": 0.83,
  "violation_type": "Не выравнена ось позвоночника",
  "violation_probs": {"spine_axis": 0.83, "...": 0.0},
  "region_probs": {"lumbar_spine": 0.97, "...": 0.0}
}
```

## 5. Интерпретация результатов

- `quality_class = 1` означает, что исследование требует внимания специалиста;
- `violation_type` перечисляет сработавшие критерии по закрытому списку
  организатора, несколько значений — через `; `; при отсутствии нарушений поле
  пустое;
- `anatomical_region` принимает значения `Поясничный отдел позвоночника` или
  `Проксимальный отдел бедра`;
- значения `quality_prob`/`violation_probs` — вероятности модели, полезны для
  приоритизации ручного просмотра.

## 6. Ограничения

- сервис не ставит диагноз и не заменяет врача;
- при малом числе редких нарушений в обучающей выборке возможны пропуски;
- для повышения точности рекомендуется периодическое дообучение на данных
  конкретного центра (см. `README.md`, раздел 12).
