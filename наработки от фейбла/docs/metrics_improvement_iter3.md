# Итерация 3: честный аудит метрик и фьюжн (наработки от Фейбла)

Дополнение к `docs/metrics_improvement.md`. Здесь — результаты проверки фьюжна
CNN + геометрия и честной оценки в метрике организатора (pooled macro-F1 по 4 меткам).

## Схема оценки

* разбиение `StratifiedGroupKFold` по `study_uid` (пациент не пересекает фолды);
* порог — только по train-части фолда;
* метрики — только по реальным снимкам (252 из 438 в манифесте);
* headline = **pooled** macro-F1 (как у организатора: один F1 по всему held-out);
* отбор источника по критерию — **вложенный** (внутри train-фолда), чтобы не подглядывать.

## Итог

| Конфигурация | Агрегация | Порог | macro-F1 |
|---|---|---|---|
| Итерация 2 (заявлено) | их harness | f1 | 0.494 |

| **Вложенный отбор карты** | **pooled** | **blend** | **0.500** |

## Порог

`blend = 0.5·(prior_thr + f1_thr)` — валидированный дефолт:

* pooled: Δ = +0.017 [+0.004; +0.030] против `prior` (ЗНАЧИМО);
* вложенная схема: Δ = +0.018 [+0.005; +0.031] (ЗНАЧИМО).

Ранговые пороги (`kprior`/`kf1`/`kblend`) — значимо хуже. `prior` vs `f1` — шум.

## Фьюжн источников (CNN / geo / geobig / fused / fusedbig)

Карта по критерию (по AUC) устойчиво выбирает геометрию только для оси позвоночника
и ROI, для остального — CNN/фьюжн. Вклад фьюжна скромный; основной эффект даёт
корректный режим порога и отбор источника, а не сама гибридизация.

## Аудит утечек

Устранены: best-epoch по val, порог на том же OOF, скейл-тег `Exposed Area`,
метаданные `copies`. Диагностика `scripts/diag_auc_leak.py` показала, что
расхождение «глобального» и честного OOF-скоров по AUC/лучшему F1/F1@prior
составляет ~0.02–0.06 на критерий — утечка стекинга мала, уровень ≈0.50 реален.

## Оговорки

* `region_accuracy = 1.000` — не метрика.
* При 6–36 позитивах рейтинг режимов порога флипается между harness'ами.
* `scripts/exp_pooled.py` выбирает карту по AUC на всём наборе — для честной оценки
  используйте `scripts/exp_pooled_nested.py` и `scripts/final_report.py --map nested`.
