# Наработки от Фейбла

Отдельный снимок работы по хакатону DXA-QC (контроль качества денситометрии).
Здесь собраны **только мои** скрипты, правки и честные результаты — без данных,
весов и PHI. Файлы команды не изменялись.

## Как применить

Это бандл-снапшот. Чтобы использовать, скопируйте файлы поверх репозитория:

```
наработки от фейбла/scripts/*.py        ->  scripts/
наработки от фейбла/dxa_qc/src/*.py     ->  dxa_qc/src/
наработки от фейбла/dxa_real/*.py       ->  dxa_real/
наработки от фейбла/docs/*.md           ->  docs/   (как отдельный файл, не затирая team-доки)
```

Все скрипты запускаются из корня репозитория и по умолчанию читают датасет из
переменной окружения `DXA_DATASET` (иначе `../_dsroot`). Приватные абсолютные
пути из кода удалены.

## Метрики (macro-F1 по 4 меткам организатора, только реальные 252 снимка)

Принцип: метрика организатора — **один F1 по всему held-out** → headline берём из
**pooled** OOF. Порог выбирается только на train-части фолда.

| Конфигурация | Агрегация | Порог | macro-F1 | Комментарий |
|---|---|---|---|---|
| Репозиторий, итерация 2 (заявлено) | их harness | f1 | 0.494 | содержит утечки |
| `dxa_qc/artifacts/metrics.json` (CV) | CV | best | 0.490 | оптимистично |
| Репозиторий, перепроверка их harness | per-fold | prior | 0.422 | честно |
| Команда, итерация 3 (`50dcce1`) | их harness | — | 0.507 | заявлено командой |
| База «команда» (cnn+axis-fused), мой pooled | pooled | prior | 0.452 | честно |
| Моя карта по AUC + blend + ансамбль | pooled | blend | 0.508 | ⚠️ отбор карты на всём наборе |
| **Вложенный отбор карты (внутри train)** | **pooled** | **blend** | **0.500** | ✅ честно |

**Главный честный результат: pooled macro-F1 ≈ 0.48–0.50** при вложенном отборе
источников (внутри train-фолда) — согласуется с заявленными командой 0.507.

### Значимые улучшения (парный бутстрэп по разбиениям)

* режим порога **`blend` = 0.5·(prior + F1-opt)** лучше `prior`: Δ=+0.017…+0.021
  (CI не накрывает 0) — оба в pooled, и во вложенной схеме;
* карта источников по критерию + `blend` лучше базовой карты команды: Δ=+0.048.

### Проверено и отброшено (честные негативные результаты)

| Идея | Результат |
|---|---|
| Ранговый порог top-k (kprior/kf1/kblend) | **хуже** `prior`/`blend` (ЗНАЧИМО) |
| Со-встречаемость меток (level-2 stacking) | метки почти не пересекаются → бесполезно, закрыто |
| Ранговый ансамбль | ни разу не выбран по AUC → нет выигрыша |
| Синтетика артефактов v2 для геометрии | AUC 0.722 → 0.716, прироста нет |
| `feat_cache.csv`-зоопарк моделей | кэш устарел, числа не сравнимы |

## Аудит утечек

Найдены и устранены:
1. выбор лучшей эпохи **по валидационному фолду**;
2. порог подбирался **на том же OOF**, по которому считалась метрика;
3. скейл-тег `Exposed Area [520,478]` как признак;
4. метаданные `copies`.

Отдельная проверка `scripts/diag_auc_leak.py`: сравнение «глобального» OOF-скора и
честного (переобучение внутри внешнего train-фолда) по AUC / лучшему F1 / F1@prior
показало расхождение всего ~0.02–0.06 на критерий — то есть **утечка стекинга мала**,
и уровень ≈0.50 реален.

## Оговорки

* `region_accuracy = 1.000` — не метрика (регион известен из разметки).
* При 6–36 позитивах рейтинг `prior` vs `f1` флипается между harness'ами — это шум.
* В `scripts/exp_pooled.py` карта источников выбирается по AUC на всём наборе
  (подглядывание) — для честной оценки используйте `scripts/exp_pooled_nested.py`
  (вложенный отбор) и `scripts/final_report.py --map nested`.
* CNN-OOF зафиксирован (seed 42), поэтому при внешних фолдах остаётся мягкое
  кросс-загрязнение — нижняя граница честности.
